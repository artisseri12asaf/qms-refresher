# Medical Device QMS Refresher

A refresher for Class II and III medical devices: ISO 13485 basics, the FDA QMSR, FDA premarket and postmarket requirements, and the EU MDR. Each chapter has takeaways, questions, debates, dilemmas and official sources, plus a Shuffle mode for random practice.

Open the site, then use "Add to Home Screen" on your phone to install it as an app. It works offline after the first visit. Answers are saved in the browser.
